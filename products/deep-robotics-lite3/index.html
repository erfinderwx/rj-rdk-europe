产品概览规格与接口组成与配套技术资料

产品概览

  • Basic 整机 12 kg，持续行走载荷 5 kg
  • 系列支持 40° 爬坡和 18 cm 台阶
  • 提供运动控制 SDK / API 与感知开发资料
  • 四个版本分别配置扩展接口与感知功能

适合的任务

  • 四足机器人教学
  • 运动控制与算法研究
  • 感知设备与上层应用开发

选择时关注

  • 先核对开发版本及其开放的软件接口。
  • 上装重量、位置和供电需与机器人载荷条件对应。
  • 研究开发版本与面向现场任务的机器人配置分别比较。

  • 运动 SDK / API
  • Ethernet（Venture / Pro / LIDAR）
  • USB 3.0 / HDMI（Pro / LIDAR）

组成与配套

产品与配置范围

  • 所选开发版本的 Lite3 机器人
  • 电池、遥控和开发附件按对应套装核对

配套选型项目

  • 对应充电设备与开发电脑
  • 扩展传感器的安装件和供电
  • 需要时增加定位或计算组件

包含项、选配件、线束及安装件按所选型号与系统配置确认。

软件与使用支持

  • SDK 和开放接口按所选开发版本使用。
  • 外部感知上装与机器人运动控制分层连接。
  • 应用算法使用对应机器人坐标系和状态接口。

使用条件

  • 载荷、接口与感知能力按所选版本使用；扩展模块重量计入持续行走载荷。
  • 续航、里程和越障参数为厂商测试数据，地形、负载与运行方式会影响实际表现。
