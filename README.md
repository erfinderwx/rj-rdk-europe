# RJ Tech Limited · 机器人产品与系统

网站：https://erfinderwx.github.io/rj-rdk-europe/

RDK 开发板、感知定位组件、移动平台与系统配置。

本仓库保存构建后的静态网站。产品需求清单由访问者在浏览器中保存、复制或下载。

## 源码与协作开发入口

网站源码保存在私有仓库 [erfinderwx/rj-rdk-europe-platform](https://github.com/erfinderwx/rj-rdk-europe-platform/tree/codex/rdk-platform)，开发分支为 `codex/rdk-platform`。

协作者请使用已获该源码仓库权限的账号打开上述链接，并阅读 [协作开发与 AI 工作提示](https://github.com/erfinderwx/rj-rdk-europe-platform/blob/codex/rdk-platform/docs/COLLABORATION.md)。其中包含源码克隆、检查与发布步骤，以及可直接交给 AI 的提示词。

本仓库的 `main` 分支保存生成网页和资源；开发请在源码仓库完成，再构建发布。直接修改生成网页，会在下一次构建发布时被覆盖。源码仓库和发布仓库的权限分别管理，AI 工具或连接器也需要获准访问私有源码仓库。

如私有仓库显示访问错误，请核对登录账号、源码仓库邀请及工具授权，并按协作说明排查。
