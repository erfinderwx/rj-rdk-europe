隐私与本地数据

以下说明当前公开演示网站的实际行为。正式接收服务与运营主体确定后，需要重新审阅并更新数据处理信息。

需求清单保存在您的浏览器

需求工作台尝试使用 localStorage 保存清单和表单；不可用时尝试 sessionStorage，再不可用时仅保留于当前页面内存。工作台显示当前保存能力。内存模式下，请在离开页面前下载或复制需求。

您可以修改、清空或导出清单。导出的 JSON 和文本可能包含您填写的联系信息，请自行保管并选择分享对象。

界面主题偏好也可保存在当前浏览器，供下次访问恢复。

需求内容不会自动提交

当前接收服务未配置，填写与生成摘要不会上传您填写的需求内容、发送邮件或创建客户记录。本网站没有广告、分析跟踪器、外部字体或第三方脚本。

GitHub Pages 托管与访问记录

在线演示由 GitHub Pages 提供静态网站托管。GitHub 的官方说明指出，访问 GitHub Pages 网站时，访问者的 IP 地址会因安全目的被记录和保存，无论访问者是否登录 GitHub。本网站的需求清单仍按上文所述保存在您的浏览器内。

有关托管服务的数据处理，请查阅 GitHub Pages 数据收集说明与 GitHub 隐私声明。官方资料核对日期：2026-10-24。

外部链接

主动打开厂商资料、源码仓库或邮件链接时，将离开本网站或打开您自己的邮件应用；相应服务按其规则处理访问。

商业运营前补充

实际数据控制者、处理目的与依据、接收方、保存期限、用户权利及联系渠道，需要在真实业务与接收服务确定后完善。
