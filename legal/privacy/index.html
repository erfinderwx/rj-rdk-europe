隐私与数据

了解需求清单的保存方式，以及访问本网站时的数据处理。

需求清单由您控制

您选择的产品、配置及填写的联系信息保存在当前浏览器中，不会自动提交。您可以编辑、清空、复制或下载清单，再自行决定是否与 RJ 分享。

网站优先使用浏览器本地存储；不可用时使用标签页会话存储，或仅保留于当前页面。需求面板显示实际保存状态。仅保留于页面时，离开或刷新会丢失内容，请先复制或下载。

导出的文本与 JSON 文件可能包含您填写的联系信息，请妥善保管。主题偏好也保存在浏览器中。网站不使用广告或分析跟踪器、外部字体或第三方脚本。

网站托管

网站由 GitHub Pages 提供静态托管。根据 GitHub 官方说明，访问者的 IP 地址会出于安全目的被记录和保存，无论访问者是否登录 GitHub。

详见 GitHub Pages 数据收集说明和 GitHub 隐私声明。

外部资料与联系

主动打开厂商资料或源码链接时，将进入相应服务；邮件链接会打开您自己的邮件应用。外部服务按其规则处理访问与您主动提供的信息。

有关本网站的隐私问题，可联系 xi.wang@xw-tech.de。
